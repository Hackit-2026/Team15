# プロダクト名

Checkit

## 概要

Checkitは単なる学習支援アプリではなく、「教室の『声にならない声』をつなぐアプリ」というコンセプトのもと、生徒と教員がリアルタイムに繋がり、授業のすれ違いを防ぐ革新的なアプリケーション。

リアルタイム学習支援システム　

問題: 分からないけれど大勢の前で手を挙げられず、疑問がそのまま放置されてしまう

解決策: 分からない瞬間、生徒が手元のスマホから匿名でワンタップ送信し、教員がダッシュボードで把握する

特徴: 「分からん」が多発するとスライドが爆発する演出と、即座の解説促進。

## 背景・課題

学校の授業や講義において、教員と学生の間にある「見えない壁」は、長年の教育現場における深刻な課題となっている。「Checkit」は、単に質問を集めるだけでなく、「授業中のリアルタイムなつまずき」を可視化することで、学生の孤立を防ぎ、教員と生徒の双方向のコミュニケーションをアップデートする学習支援アプリケーションである。

教室が抱えるリアルな課題と解決したいこと
背景: 大人数で行われる現代の講義では、教員側が生徒一人ひとりの細かな理解度や「今どこで迷っているか」をリアルタイムで正確に把握することが極めて困難である。

課題: 学生側は「ここが分からない」と感じていても、周囲の目を気にして大勢の前で手を挙げたり質問したりすることができず、声を飲み込んでしまう。

結果: 疑問がその場に放置されたまま授業が先に進んでしまい、知らず知らずのうちに授業についていけなくなる生徒が生まれてしまう。

こうした現状や結果を踏まえ、私たちは「授業から誰も置いていかないための仕組み」が必要だと強く実感し、このアプリケーションを開発した。

「Checkit」が目指す解決策
開発の原点: 「分からん」がその場に放置される悪循環を断ち切り、声を上げられない学生が救われる教室をつくりたいという思いから開発をスタート。

解決のアプローチ: 生徒が手元のスマホから匿名でワンタップで「分からん」を送信でき、教員側がダッシュボードで全体のつまずきをリアルタイムかつ一目で把握できる仕組みを構築した。

プロダクトの価値: 「分からん」が多発すると画面上のスライドが爆発するユニークな演出を取り入れることで、教室の沈黙を打破し、教員へ即座に危機感を伝えてその場での手厚い解説を促す新しい学習体験を提供する。
## 主な機能

★生徒側の主要機能

１.「分からん」ボタンによる手軽な意思表示

　　・授業中に画面に表示されるボタンを押すだけで、大勢の前で声を出すことなく<br>
  　　　自分の「わからない」を気軽に伝えることができる。

２.匿名ログインによる自動履歴保存

　　・メールアドレス不要の匿名ログインに対応しており、プライバシーを守りながら、<br>
  　　　ボタンを押したタイミングのスライド番号を自動で記録する。

３.つまずきメモ機能による高い見返しやすさ

　　・記録されたスライドの位置情報に加え、「何が分からなかったか」のメモを一緒に<br>
  　　　付属して保存できるため、授業後の復習や見直しがスムーズに行える。

<br />

★教師側の主要機能

１.担当科目ごとの「分からん」記録とフィードバック

　　・教員が担当する科目ごとに、「分からん」が押された回数や該当するスライド番号が記録されるため、<br>
  　　　授業後の振り返りや生徒へのフィードバックがスムーズに行える。

２.リアルタイムな顔文字フィードバック（🤔の表示）

　　・授業の最中に生徒が「分からん」を押すと、教員側のスライドにリアルタイムで<br>
  　　　「わからない顔🤔」が表示され、教室全体の反応が直感的に伝わる。

３.一定回数超過による「スライド爆発」アラート

　　・短時間に一定回数以上の「分からん」が押されると、画面上のスライドが爆発する演出が発生し、<br>
　　　教員へ強い危機感を伝えることで、その場ですぐに立ち止まって解説を促す<br>
  　　　リアルタイムフィードバックを実現する。

## 今後の展望

★追加機能と今後の展望

１.学生用個人ページの作成

　　・授業ごとに記録された「わからない」の履歴や付属のメモ、該当するスライド番号をマイページ上で一元管理できる。<br>
  　　　自分のつまずきの傾向や苦手なポイントを後から簡単に振り返ることができ、<br>
     　　　自学自習やテスト前の復習効率を飛躍的に高める。

2. AIによるスライドの重要単語抽出機能

授業のスライドデータをAIが自動で解析し、そのページにおける重要単語やキーワードを分かりやすくピックアップして表示する。

学生が復習する際に要点を素早くキャッチできるようにし、効率的な理解と定着をサポートする。

3. 実際の講義での実証実験とサービス拡大

ハッカソンでの開発にとどまらず、実際の学校や大学の講義に試験導入し、教員と学生双方のフィードバックをもとにさらなる機能改善と運用テストを進める。
