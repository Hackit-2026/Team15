# プロダクト名

Checkit

## 概要

授業中の「わからない」を匿名でリアルタイムに可視化する学習支援アプリ『Checkit』です。
生徒はワンタップで気軽に意思表示ができ、教員側はダッシュボードで全体のつまずきを把握できます。
「わからない」が多発するとスライドが爆発する演出により、教室の沈黙を打破して即座の解説を促します。
