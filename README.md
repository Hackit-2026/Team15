# プロダクト名

Checkit

## 概要

Checkitは単なる学習支援アプリではありません。「教室の『声にならない声』をつなぐアプリ」というコンセプトのもと、生徒と教員がリアルタイムに繋がり、授業のすれ違いを防ぐ革新的なアプリケーションです。

リアルタイム学習支援システム　

問題: 分からないけれど大勢の前で手を挙げられず、疑問がそのまま放置されてしまう

解決策: 分からない瞬間、生徒が手元のスマホから匿名でワンタップ送信し、教員がダッシュボードで把握する

特徴: 「わからない」が多発するとスライドが爆発する演出と、即座の解説促進。
